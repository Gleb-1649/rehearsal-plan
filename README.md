# План репетиций

Здесь можно собрать задачи к репетиции: упражнения, партии и подготовку к выступлению.
Это ToDo для лабораторной № 2, без сторонних библиотек.

**Управление**

| Действие | Как сделать |
|---|---|
| Добавить запись | «Новая задача», затем название, дата и «Записать» |
| Поправить запись | «Править» на нужной карточке |
| Выйти из окна без правок | Escape или «Закрыть без сохранения» |
| Завершить задачу | «Готово»; можно вернуть её в работу |
| Удалить | «Убрать» |

Над карточками есть поиск и кнопки «Все», «В работе», «Готово».
Два поля дат задают период вместе с его границами. Для одного дня укажите одну и ту же дату в обоих полях.

**Расстановка карточек**

В списке «Расположение» можно выбрать сортировку по дате или «Как расставил я».
Ручная перестановка доступна с очищенными фильтрами: перетащите карточку на левую половину соседней,
чтобы поставить перед ней, или на правую — чтобы поставить после.

План записывается в хранилище браузера. При следующем открытии вернутся карточки и отметки выполнения.
Настройки поиска не запоминаются. При ошибке сохранения появляется предупреждение;
после успешной записи оно исчезает.

**Расположение кода**

```text
scripts/main.js      страница, кнопки и карточки
scripts/storage.js   чтение и запись плана
scripts/data.js      подписи элементов управления
styles/main.css      внешний вид
images/favicon.svg   значок вкладки
```

Для просмотра подойдёт Live Server: открыть папку в редакторе и запустить `index.html`.
Прямое открытие через `file://` не подходит для импортов JavaScript.
